`wiktionary-closed-class.json` holds English articles, pronouns, prepositions,
conjunctions, determiners, particles, interjections and contractions adapted
from [Wiktionary](https://en.wiktionary.org) via the [kaikki.org](https://kaikki.org)
extracts. It is generated by `scripts/distill-wiktionary.mjs` and is available
under the [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/) license.
